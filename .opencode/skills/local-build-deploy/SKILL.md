# local-build-deploy

在原生 Windows x64 环境构建当前工作树中的 Markpad，并安全部署便携版程序。用户只说“构建”时，默认继续完成验证、构建、部署和启动冒烟测试；只有用户明确要求“只构建、不部署”时才在产物验证后停止。

## 固定路径与产物

- 仓库根：当前 Markpad Git 工作树根目录
- 构建产物：由 Cargo metadata 的 `target_directory` 派生 `<target_directory>\x86_64-pc-windows-msvc\release\Markpad.exe`
- NSIS 产物：同一 target 下的 `release\bundle\nsis\*-setup.exe`，仅报告，不执行
- 部署目录：`D:\Program\Markpad`
- 活动程序：`D:\Program\Markpad\Markpad.exe`

## 前置检查

1. 确认操作系统是 Windows，进程架构为 x64/AMD64。其他平台或 ARM64 环境停止，不猜测交叉编译和部署路径。
2. 确认当前目录是 Markpad 仓库根，且存在 `package.json`、`package-lock.json` 和 `src-tauri\Cargo.toml`。
3. 确认 Node.js 主版本为 24，并确认 npm、`rustc`、`cargo` 可用。Rust 使用 stable 工具链。
4. 读取 `git status --short --branch` 并向用户说明本次构建是否包含未提交改动。构建允许使用脏工作区，但不得自动 stash、提交、清理或丢弃改动。
5. 默认部署时确认 `D:\Program\Markpad` 已存在且是目录。目录缺失时停止并询问用户，不擅自选择其他安装位置。
6. 本流程不需要 Tauri updater 签名私钥。不要读取、打印、生成或写入任何签名密钥。

## 流程

### 1. 安装锁定依赖

使用 CI 相同的锁文件安装方式：

```powershell
npm ci
if ($LASTEXITCODE -ne 0) { throw "npm ci failed with exit code $LASTEXITCODE" }
```

失败时停止。不要改用 `npm install` 绕过锁文件问题。

### 2. 完整质量检查

按 CI 顺序执行：

```powershell
npm audit
if ($LASTEXITCODE -ne 0) { throw "npm audit failed with exit code $LASTEXITCODE" }
npm run check
if ($LASTEXITCODE -ne 0) { throw "npm run check failed with exit code $LASTEXITCODE" }
node --test --import tsx scripts/*.test.ts
if ($LASTEXITCODE -ne 0) { throw "Node tests failed with exit code $LASTEXITCODE" }
npm run test:vitest
if ($LASTEXITCODE -ne 0) { throw "Vitest failed with exit code $LASTEXITCODE" }

Push-Location src-tauri
try {
    cargo fmt --check
    if ($LASTEXITCODE -ne 0) { throw "cargo fmt --check failed with exit code $LASTEXITCODE" }
    cargo test
    if ($LASTEXITCODE -ne 0) { throw "cargo test failed with exit code $LASTEXITCODE" }
    cargo clippy --all-targets -- -D warnings
    if ($LASTEXITCODE -ne 0) { throw "cargo clippy failed with exit code $LASTEXITCODE" }
} finally {
    Pop-Location
}
```

Windows 下不能使用 `npm test` 代替 `node --test --import tsx scripts/*.test.ts`，否则 `cmd.exe` 可能把单引号 glob 当作文件名并静默运行 0 项测试。

任一步骤失败都停止，不进入构建或部署。报告失败命令、退出码、关键错误，以及失败是否可能与当前未提交改动有关。

### 3. 构建并证明 Windows x64 产物

以下代码必须在同一次 PowerShell 7 调用中执行。它显式指定 Windows x64 MSVC target，通过 Cargo metadata 确定有效 target 目录，并在构建前删除该目标下的旧 EXE。构建成功后只接受本次重新生成且 PE machine 为 x64 的文件，不能根据旧文件、文件名或日志猜测版本。

```powershell
$ErrorActionPreference = "Stop"
$targetTriple = "x86_64-pc-windows-msvc"
$rustVersionInfo = @(rustc -vV)
if ($LASTEXITCODE -ne 0) { throw "rustc -vV failed with exit code $LASTEXITCODE" }
$rustHost = ($rustVersionInfo | Where-Object { $_ -like "host:*" }) -replace '^host:\s*', ''
if ($rustHost -ne $targetTriple) { throw "Expected Rust host $targetTriple, got $rustHost" }

Push-Location src-tauri
try {
    $cargoMetadata = cargo metadata --no-deps --format-version 1 | ConvertFrom-Json
    if ($LASTEXITCODE -ne 0) { throw "cargo metadata failed with exit code $LASTEXITCODE" }
} finally {
    Pop-Location
}

$targetDirectory = $cargoMetadata.target_directory
$source = Join-Path $targetDirectory "$targetTriple\release\Markpad.exe"
if (Test-Path -LiteralPath $source -PathType Leaf) {
    Remove-Item -LiteralPath $source -Force -ErrorAction Stop
}

$buildStarted = [DateTime]::UtcNow
npm run tauri build -- --no-sign --target $targetTriple
if ($LASTEXITCODE -ne 0) { throw "Tauri build failed with exit code $LASTEXITCODE" }
if (-not (Test-Path -LiteralPath $source -PathType Leaf)) {
    throw "This build did not produce the expected artifact: $source"
}

$sourceItem = Get-Item -LiteralPath $source
$sourceVersion = $sourceItem.VersionInfo.ProductVersion
$packageVersion = (Get-Content -LiteralPath "package.json" -Raw | ConvertFrom-Json).version
$cargoVersion = ($cargoMetadata.packages | Where-Object { $_.name -eq "Markpad" }).version

if ($sourceItem.Length -le 0) { throw "Built Markpad.exe is empty" }
if ($sourceItem.LastWriteTimeUtc -lt $buildStarted.AddSeconds(-2)) { throw "Built Markpad.exe was not generated by this build" }
if ([string]::IsNullOrWhiteSpace($sourceVersion)) { throw "Built Markpad.exe has no ProductVersion" }
if ($sourceVersion -ne $packageVersion -or $sourceVersion -ne $cargoVersion) {
    throw "Version mismatch: exe=$sourceVersion package.json=$packageVersion Cargo.toml=$cargoVersion"
}

$reader = $null
$stream = [System.IO.File]::Open($source, 'Open', 'Read', 'Read')
try {
    $reader = [System.IO.BinaryReader]::new($stream)
    $stream.Position = 0x3c
    $peOffset = $reader.ReadInt32()
    $stream.Position = $peOffset
    $peSignature = $reader.ReadUInt32()
    $machine = $reader.ReadUInt16()
} finally {
    if ($null -ne $reader) { $reader.Dispose() } else { $stream.Dispose() }
}
if ($peSignature -ne 0x00004550 -or $machine -ne 0x8664) {
    throw "Expected an x64 PE executable, signature=0x$($peSignature.ToString('X8')) machine=0x$($machine.ToString('X4'))"
}

$sourceHash = (Get-FileHash -LiteralPath $source -Algorithm SHA256).Hash
$nsisDirectory = Join-Path $targetDirectory "$targetTriple\release\bundle\nsis"
Write-Output "[build] artifact=$source"
Write-Output "[build] version=$sourceVersion"
Write-Output "[build] sha256=$sourceHash"
Write-Output "[build] nsis-directory=$nsisDirectory (not executed)"
```

`--no-sign` 是本地验证约束：不创建签名发布物，不依赖 `TAURI_SIGNING_PRIVATE_KEY`。构建失败、目标文件未重新生成、版本不一致或 PE 架构不符时不得部署旧产物。记录输出的绝对产物路径和 SHA256；后续把 `<VALIDATED_SOURCE_PATH>`、`<VALIDATED_SOURCE_SHA256>` 替换为这两个字面值，不能在等待用户关闭 Markpad 后改用另一个同版本文件。

如果用户明确要求“只构建、不部署”，在此报告便携版和 NSIS 产物路径后结束。不要检查或关闭进程，不修改安装目录，不启动产物。

### 4. 部署前进程门禁

部署前检查所有名为 `Markpad` 的进程：

```powershell
$running = @(Get-Process -ErrorAction Stop | Where-Object { $_.ProcessName -eq "Markpad" })
if ($running.Count -gt 0) {
    $running | Select-Object Id, ProcessName, Path
    throw "Markpad is running. Ask the user to close every Markpad window, then retry deployment."
}
```

发现进程时停止并请用户自行退出。禁止使用 `Stop-Process`、`taskkill`、WMI terminate 或其他强杀方式，因为应用可能仍有未保存文档。

### 5. 加锁、原子替换、校验和冒烟

以下 PowerShell 7 代码必须作为一次完整调用执行。命名 mutex 覆盖进程复查、暂存、原子备份替换、哈希校验、启动冒烟和失败回滚，防止两个部署流程交错。`File.Replace` 在同一个原子操作中把替换前目标写入唯一备份并安装新文件，不存在“先复制备份、再替换”之间的竞争窗口。

```powershell
$ErrorActionPreference = "Stop"
$targetTriple = "x86_64-pc-windows-msvc"
Push-Location src-tauri
try {
    $cargoMetadata = cargo metadata --no-deps --format-version 1 | ConvertFrom-Json
    if ($LASTEXITCODE -ne 0) { throw "cargo metadata failed with exit code $LASTEXITCODE" }
} finally {
    Pop-Location
}
$source = "<VALIDATED_SOURCE_PATH>"
$validatedSourceHash = "<VALIDATED_SOURCE_SHA256>"
$expectedSource = Join-Path $cargoMetadata.target_directory "$targetTriple\release\Markpad.exe"
if ([System.IO.Path]::GetFullPath($source) -ne [System.IO.Path]::GetFullPath($expectedSource)) {
    throw "Validated artifact path does not match Cargo metadata: validated=$source expected=$expectedSource"
}
$installDirectory = "D:\Program\Markpad"
$target = Join-Path $installDirectory "Markpad.exe"
if (-not (Test-Path -LiteralPath $installDirectory -PathType Container)) {
    throw "Install directory does not exist: $installDirectory"
}

$mutex = [System.Threading.Mutex]::new($false, "Global\MarkpadLocalBuildDeploy")
$mutexAcquired = $false
$temporary = $null
try {
    try {
        $mutexAcquired = $mutex.WaitOne(0)
    } catch [System.Threading.AbandonedMutexException] {
        $mutexAcquired = $true
    }
    if (-not $mutexAcquired) { throw "Another Markpad deployment is already running" }

    $running = @(Get-Process -ErrorAction Stop | Where-Object { $_.ProcessName -eq "Markpad" })
    if ($running.Count -gt 0) {
        throw "Markpad started again before deployment. Close it and retry."
    }

    $sourceItem = Get-Item -LiteralPath $source
    $sourceVersion = $sourceItem.VersionInfo.ProductVersion
    $packageVersion = (Get-Content -LiteralPath "package.json" -Raw | ConvertFrom-Json).version
    if ($sourceItem.Length -le 0 -or [string]::IsNullOrWhiteSpace($sourceVersion) -or $sourceVersion -ne $packageVersion) {
        throw "Build artifact validation failed immediately before deployment"
    }
    $sourceHash = (Get-FileHash -LiteralPath $source -Algorithm SHA256 -ErrorAction Stop).Hash
    if ($sourceHash -ne $validatedSourceHash) {
        throw "Build artifact changed after validation; rebuild before deployment"
    }

    $targetExisted = Test-Path -LiteralPath $target -PathType Leaf
    $timestamp = Get-Date -Format "yyyyMMdd-HHmmss"
    $oldVersion = if ($targetExisted) { (Get-Item -LiteralPath $target).VersionInfo.ProductVersion } else { "none" }
    $safeOldVersion = if ([string]::IsNullOrWhiteSpace($oldVersion)) { "unknown" } else { $oldVersion -replace '[^0-9A-Za-z._-]', '_' }
    $unique = [Guid]::NewGuid().ToString('N')
    $backup = Join-Path $installDirectory "Markpad.$safeOldVersion.$timestamp.$unique.backup.exe"
    $temporary = Join-Path $installDirectory "Markpad.deploy.$PID.$unique.tmp.exe"

    Copy-Item -LiteralPath $source -Destination $temporary -ErrorAction Stop
    $temporaryHash = (Get-FileHash -LiteralPath $temporary -Algorithm SHA256 -ErrorAction Stop).Hash
    if ([string]::IsNullOrWhiteSpace($temporaryHash) -or $temporaryHash -ne $sourceHash) {
        throw "Staged deployment hash does not match the build artifact"
    }

    $replacementCompleted = $false
    $backupHash = $null
    try {
        if ($targetExisted) {
            [System.IO.File]::Replace($temporary, $target, $backup, $true)
            $replacementCompleted = $true
            $backupHash = (Get-FileHash -LiteralPath $backup -Algorithm SHA256 -ErrorAction Stop).Hash
            if ([string]::IsNullOrWhiteSpace($backupHash)) { throw "Atomic backup hash is empty" }
        } else {
            Move-Item -LiteralPath $temporary -Destination $target -ErrorAction Stop
            $replacementCompleted = $true
        }
        $temporary = $null

        $targetHash = (Get-FileHash -LiteralPath $target -Algorithm SHA256 -ErrorAction Stop).Hash
        if ([string]::IsNullOrWhiteSpace($targetHash) -or $targetHash -ne $sourceHash) {
            throw "Deployed file hash does not match the build artifact"
        }

        $smokeProcess = Start-Process -FilePath $target -PassThru -ErrorAction Stop
        Start-Sleep -Seconds 5
        $smokeProcess.Refresh()
        if ($smokeProcess.HasExited) { throw "Deployed Markpad exited during the startup smoke test" }
    } catch {
        $operationError = $_
        if ($replacementCompleted) {
            try {
                if ($targetExisted) {
                    if (-not (Test-Path -LiteralPath $backup -PathType Leaf)) { throw "Deployment backup is missing" }
                    if ([string]::IsNullOrWhiteSpace($backupHash)) {
                        $backupHash = (Get-FileHash -LiteralPath $backup -Algorithm SHA256 -ErrorAction Stop).Hash
                    }
                    [System.IO.File]::Replace($backup, $target, $null, $true)
                    $restoredHash = (Get-FileHash -LiteralPath $target -Algorithm SHA256 -ErrorAction Stop).Hash
                    if ($restoredHash -ne $backupHash) { throw "Restored installation hash does not match the backup" }
                } elseif (Test-Path -LiteralPath $target -PathType Leaf) {
                    Remove-Item -LiteralPath $target -Force -ErrorAction Stop
                    if (Test-Path -LiteralPath $target) { throw "New deployment target still exists after rollback" }
                }
            } catch {
                throw "Deployment failed ($operationError) and rollback also failed: $($_.Exception.Message). Target=$target Backup=$backup"
            }
            throw "Deployment failed and the previous installation was restored: $operationError"
        }
        throw
    }

    Write-Output "[deploy] target=$target"
    Write-Output "[deploy] backup=$(if ($targetExisted) { $backup } else { '<none>' })"
    Write-Output "[deploy] version=$sourceVersion"
    Write-Output "[deploy] sha256=$targetHash"
    Write-Output "[smoke] Markpad is running with pid=$($smokeProcess.Id)"
} finally {
    if ($null -ne $temporary -and (Test-Path -LiteralPath $temporary)) {
        try { Remove-Item -LiteralPath $temporary -Force -ErrorAction Stop } catch { Write-Warning "Temporary file cleanup failed: $_" }
    }
    if ($mutexAcquired) {
        $mutex.ReleaseMutex()
    }
    $mutex.Dispose()
}
```

不要直接对活动目标执行 `Copy-Item -Force`，不要运行 NSIS 安装器。成功部署后保留版本化备份和新 Markpad 进程，供用户手动验证打开、编辑、预览和保存。任何替换后错误都进入同一回滚路径并核对恢复哈希；若已启动进程仍锁定目标导致回滚失败，绝不强杀，立即报告目标、备份和错误。

### 6. 汇总

报告：

- 当前分支、提交 ID，以及是否包含未提交改动。
- Node、npm、Rust 和 Cargo 版本。
- 每项质量检查结果，确认 Node 测试实际执行数量不是 0。
- 构建产物、ProductVersion、大小和 SHA256。
- NSIS 产物路径，并明确说明未执行安装器。
- 部署目标、备份路径、目标 SHA256 和冒烟进程 ID。

## 不在本流程内

- 不运行 `npm run release`，不修改 `package.json`、`Cargo.toml` 或 `Cargo.lock` 版本。
- 不提交、打 tag、推送、创建 GitHub release 或触发 GitHub Actions。
- 不运行 NSIS 安装器，不修改 Windows 卸载信息或快捷方式。
- 不使用 updater 私钥，不修改 updater endpoint 或 `plugins.updater.pubkey`。
- 不构建或发布 ARM64、macOS、Linux、Chocolatey 或 Snap 产物。
- 不自动清理 `src-tauri\target`、`node_modules` 以外的用户文件或历史部署备份。

## 安全规则

- 依赖安装、质量检查、构建或产物校验失败：不得部署。
- Markpad 仍在运行：不得覆盖，不得强杀，等待用户自行退出。
- 临时文件哈希不匹配：删除临时文件并停止，保留当前安装。
- 替换后哈希或启动冒烟失败：恢复备份并报告。
- 默认仅替换便携版 `D:\Program\Markpad\Markpad.exe`；用户明确要求只构建时不触碰安装目录。
